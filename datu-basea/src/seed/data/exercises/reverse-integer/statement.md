32 biteko zenbaki oso ikurdun bat (`x`) emanda, itzuli `x` bere _digituak alderantzikatuta_. Alderantzikatzeak balioa 32 biteko zenbaki oso ikurdunaren tartetik **[-2³¹, 2³¹ - 1]** kanpo ateratzen badu, itzuli `0`.

**Suposatu ingurumenak ez duela baimentzen 64 biteko zenbaki osoak gordetzea (ikurdunak edo ikurgabeak).**

&nbsp;

**1. adibidea:**

```
Sarrera: x = 123
Irteera: 321
```

**2. adibidea:**

```
Sarrera: x = -123
Irteera: -321
```

**3. adibidea:**

```
Sarrera: x = 120
Irteera: 21
```

&nbsp;

Murrizpenak:

- 2³¹ ≤ x ≤ 2³¹ - 1
