Emanda `x` zenbaki oso bat, itzuli `true` `x` _palindromoa_ bada, eta `false` bestela.

**1. adibidea:**

```
Sarrera: x = 121
Irteera: true
Azalpena: 121 ezkerretik eskuinera 121 irakurtzen da, eta eskuinetik ezkerrera ere bai.
```

**2. adibidea:**

```
Sarrera: x = -121
Irteera: false
Azalpena: Ezkerretik eskuinera, -121 irakurtzen da. Eskuinetik ezkerrera, 121- bihurtzen da. Beraz, ez da palindromoa.
```

**3. adibidea:**

```
Sarrera: x = 10
Irteera: false
Azalpena: Eskuinetik ezkerrera 01 irakurtzen da. Beraz, ez da palindromoa.
```

**Murrizketak:**

- `-2^31 <= x <= 2^31 - 1`

**Hurrengo pausoa:** Ebatzi al dezakezu zenbaki osoa katera bihurtu gabe?
